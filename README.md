# Data Science and Machine Learning Tool (DSML Tool)
------------------------------------------------------

This software is initially developed by [Abit K Sebin](http://abitkseb.in/) as part of dissertaion during the M.Tech Data Science and Engineering programme.

## Why DSML Tool?

In the modern corporate world, data-driven solution-making is necessary so, data science and machine learning trainings are given to a lot of professionals to use in their day-to-day work. Many technical and management professionals who don’t know programming have difficulty exploring data science and trying different machine learning algorithms. But they may need it for improving their business with data-driven decisions. This consumes a lot of time and effort for them to search code snippets from the internet and make it run using the Jupyter notebook. Although there are some tools which help users to do data analysis and machine learning, in-depth knowledge is required to effectively use the tool. Otherwise, users get confused with all the features given in such tools. So, we need a tool that has only the necessary options for a basic level user to perform data science and machine learning activities without writing any code. It should also have the capability to store the trained model for future use.

This project gives a solution for that problem by the development of a standalone application built using Python which has all the necessary functionalities required from pre-processing data to training the model and exporting it. The objective of this project is to help people who don’t know programming to use the data science capabilities of Python through this tool’s user interface without writing any code. This tool will provide the functionality to load data files, clean and pre-process them using various options, combine multiple files, perform data cleaning, data analysis using basic visualizations, feature extraction, train different machine learning models and export the trained models to files for future usage, load and use previously trained model etc. This tool will reduce the time and effort a user who doesn’t have programming skills consumes to create a machine learning model by writing Python code, thus improving productivity and reducing the cost.



### Running the program

```sh
python dsmltool
```
